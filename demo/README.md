# Application preview images

These PNG files are application UI captures from browser-test preview runs using
illustrative fixtures. They are not live screenshots of the reader's environment.
Host names, IP addresses, displayed PINs, chat messages, transfer percentages, and
rates are sample data. Displayed rates must not be used as benchmark results.
Exact controls and layout may differ from the installed build.

| Image | View |
| --- | --- |
| [home-dark.png](home-dark.png) | Landing screen and host/client entry points. |
| [transfers-dark.png](transfers-dark.png) | Client queue with illustrative transfer states. |
| [host-rules-dark.png](host-rules-dark.png) | Host dashboard, receiving permissions, extension selection, and size limit. |
| [chat-light.png](chat-light.png) | Host interface with device chat in the light theme. |
| [home-light.png](home-light.png) | Welcome screen and host/join options in the white/light theme. |
| [host-search.png](host-search.png) | Still capture of the radar-style host-search animation during discovery. |

The images are embedded using relative paths in the root README, so they work
when the repository is viewed on GitHub or downloaded with this folder intact.
Static captures illustrate appearance, not animation, accessibility conformance,
successful network transfer, or current integration-test status.

## Add this documentation bundle to the repository

1. Replace the root `README.md` with the supplied file.
2. Copy this entire `demo/` directory alongside it.
3. Keep the existing source, tests, tools, and other documentation folders intact.
   This bundle is not a complete application download.
4. Commit both `README.md` and `demo/` to Git so image links resolve on GitHub.

## Including images in generated source packages

The source packaging tool uses an explicit folder allowlist. Git includes these
files normally, but source archives generated by `tools/package_source.py` need
the following entry in its existing `folders` dictionary to retain the previews:

```python
'demo': {'.png', '.md'},
```

Keep its other entries unchanged. This documentation-only bundle does not modify
that tool. Regenerate source packages and their manifest after documentation
changes; do not reuse a manifest generated before those changes. Choose a new
output archive name because the packager intentionally refuses to overwrite an
existing archive.
